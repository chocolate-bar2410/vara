---
title: Installation
---
The prefered way to install Vara is by using [ember](https://emberpm.dev/), a toolchain and package manager for luau projects.
Other toolchain managers like rokit can also be used to install vara.

=== "ember"
    ```
    embr tool add chocolate-bar2410/vara
    ```

=== "rokit"
    ```
    rokit add chocolate-bar2410/vara
    ```

You can also download the binaries directly from the [github repository](https://github.com/chocolate-bar2410/vara/releases) if you dont already have a toolchain manager.

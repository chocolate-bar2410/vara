# Vara
<p>
Build desktop applications with luau.
<p>
<p>
Turn luau into a language for desktop development.
Vara is a lightweight runtime that provides native system access, media processing and resource management 

Build native applications without the overhead of web runtimes.
</p>

<div class="homepage-feature_list">
<span class="homepage-feature" markdown> 
<div class="feature-title">Native media processing</div>
<div class="feature-desc">
Load, Transform and export media directly from luau.
Build tooling and automated pipelines for image and audio processing.

No external bindings or FFI needed.
</div>
</span>

<span class="homepage-feature" markdown> 
<div class="feature-title">Operating system access</div>
<div class="feature-desc">
Access information on the operating system, device details, and user preferences directly from Luau.
Make Luau feel like a language that belongs on your desktop.
</div>
</span>

<span class="homepage-feature" markdown> 
<div class="feature-title">Native resource objects</div>
<div class="feature-desc">
Files, directories, dates, images and audio are encapsulated as luau objects with their own properties and methods.
</div>
</span>
</div>

# Usage
```pwsh
vara setup
```

Generates type definition files and sets up a `.luaurc` file.  
if a `.luaurc` file doesn't exist it will generate one for you.

!!! info
    This assumes you're using vscode, editors like neovim or emacs aren't entirely supported yet.  
    If you want to use this with an editor other than vscode you must manually register the .d.luau files to luau lsp.

    Support for other editors will come soon.
